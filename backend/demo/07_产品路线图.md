# 星辰科技 — 2026 年度产品路线图

## 愿景

星辰科技 2026 年的核心目标：**成为中国企业级 AI 知识管理领域的领导者**。

**路线图制定人**：林小雅（产品总监）
**审核人**：李博文（CTO）、张明远（CEO）

## Q1（已完成）

### 已交付

| 产品 | 版本 | 核心功能 | 上线日期 |
|------|------|----------|----------|
| 智能客服平台 | v4.2 | 情感分析模块、工单自动分类 | 2026.01.15 |
| 知识图谱构建平台 | v2.1 | LightRAG 自动图谱构建优化 | 2026.02.01 |

- 知识图谱构建平台最大图谱规模达到 23 万实体

## Q2 计划

### 智能客服平台 v5.0（预研）

- **优先级**：P1
- **负责人**：周建华（后端组组长）
- **计划功能**：
  - 微服务架构重构（支持 10,000 路并发）
  - 语音客服（接入语音识别和语音合成）
  - 主动营销（基于用户画像的智能推荐）
  - 多语言支持（英语、日语、泰语）

### 知识图谱构建平台 v2.5

- **优先级**：P1
- **负责人**：林小雅（产品总监）
- **计划功能**：
  - 图谱质量评估工具（自动检测冗余和矛盾实体）
  - 增量更新机制（支持实时文档更新图谱）
  - 图谱推理引擎（基于关系的逻辑推理）
  - 行业模板库（医疗、金融、制造预设模板）

### 星辰大模型 v2.5

- **优先级**：P0
- **负责人**：黄伟（AI 实验室主任）
- **计划功能**：
  - 代码能力专项优化（HumanEval ≥85）
  - 长上下文优化（256K tokens）
  - Agent 能力增强（工具调用准确率 ≥95%）
  - 模型压缩（8B 版本，面向边缘部署）

### 星辰大模型 v3.0（预研）

- **优先级**：P0
- **负责人**：黄伟（AI 实验室主任）
- **预算**：800 万元
- **计划功能**：
  - 参数规模 200B
  - 视频多模态理解
  - 世界模型（物理常识推理）

## Q3 计划

### 智能客服平台 v5.0 正式版

- 微服务架构正式上线
- 首批灰度客户：招商银行信用卡中心、比亚迪供应链管理部
- 预计支撑 10,000 路并发

### 知识图谱构建平台海外版

- **级别**：P1 项目
- **负责人**：林小雅（产品总监）
- **目标市场**：新加坡、东南亚
- **功能**：
  - 多语言 UI（英语、日语、马来语）
  - 符合新加坡 PDPA 数据保护法规
  - 部署在新加坡 AWS 区域

### 星辰大模型 API v3.0 测试版

- 200B 参数模型面向部分客户开放内测
- 首批内测客户：清华大学继续教育学院、新东方教育科技集团

## Q4 计划

### 星辰大模型 v3.0 正式版

- 200B 参数模型正式上线
- 视频多模态能力
- 世界模型推理

### 智能客服平台 v6.0（预研）

- 全模态客服（文本 + 语音 + 视频）
- Agent 化（自主调用工具完成任务）

### 知识图谱构建平台 v3.0

- 支持实时流式图谱更新
- 图谱推理引擎正式版
- 跨知识库图谱融合
