## 产品一：智能客服平台

### 产品定位

基于大语言模型的智能客服解决方案，替代传统规则驱动的客服机器人，实现自然语言理解、多轮对话和工单自动处理。

### 核心功能

| 功能 | 说明 | 支持版本 |
|------|------|----------|
| 智能对话 | 基于大模型的多轮自然语言对话 | v4.0+ |
| 工单自动分类 | 自动识别工单类型并分配到对应部门 | v3.5+ |
| 情感分析 | 实时分析用户情绪，负面情绪时自动转人工 | v4.2+ |
| 知识库检索 | 对接企业知识库，自动检索并生成回答 | v3.0+ |
| 多渠道接入 | 支持网站、APP、微信小程序、电话 | v2.0+ |
| 数据看板 | 实时监控对话量、满意度、转人工率 | v3.0+ |

### 技术指标

- 对话准确率：92%（基于招商银行信用卡中心实测数据）
- 意图识别准确率：96%
- 平均响应时间：1.2 秒
- 支持并发量：5,000 路对话
- 可对接的知识库类型：Milvus、LightRAG、Elasticsearch

## 产品二：知识图谱构建平台

### 产品定位

帮助企业从非结构化文档中自动构建知识图谱，支持图谱可视化、语义搜索和智能推理。

### 核心功能

| 功能 | 说明 |
|------|------|
| 文档解析 | 支持 PDF、Word、Markdown、图片格式，集成 MinerU/PaddleX |
| 自动图谱构建 | 基于 LightRAG，LLM 自动抽取实体和关系 |
| 手动图谱编辑 | 支持 JSONL 格式手动上传三元组 |
| 图谱可视化 | Sigma.js 力导向布局，支持交互式探索 |
| 语义搜索 | 向量 + 图谱混合检索 |
| API 输出 | 提供 RESTful API 供第三方系统调用 |

### 技术指标

- 支持文档格式：PDF、DOCX、Markdown、PNG、JPG
- 实体抽取准确率：89%（基于通用企业文档）
- 关系抽取准确率：82%
- 最大支持图谱规模：500 万实体、2,000 万关系
- 查询响应时间：500ms 以内（百万级图谱）

- **主要用途**：医学文献知识管理、临床决策支持
- **处理文档量**：累计 12 万页医学文献
- **对接人**：黄伟（算法组组长）

## 产品三：星辰大模型 API

### 产品定位

基于自研「星辰大模型 v2.0」提供标准化 API 服务，支持文本生成、代码生成、多模态理解等能力。

### 模型参数

- **参数量**：70B
- **训练数据**：12T tokens（中英双语，截至 2025 年 12 月）
- **上下文长度**：128K tokens
- **支持模态**：文本、图片
- **训练硬件**：1,024 × NVIDIA H100（采购自英伟达）

### 能力列表

| 能力 | 说明 | 评测得分 |
|------|------|----------|
| 文本生成 | 文章写作、报告生成、摘要总结 | C-Eval: 85.3 |
| 代码生成 | 支持 20+ 编程语言 | HumanEval: 78.6 |
| 多模态理解 | 图片内容分析、OCR、图表理解 | MMMU: 62.1 |
| 逻辑推理 | 数学计算、逻辑推演 | GSM8K: 89.2 |
| 知识问答 | 通用知识、行业知识 | CMMLU: 83.7 |

### API 定价

| 模型 | 输入价格（元/百万 tokens） | 输出价格（元/百万 tokens） |

| 星辰大模型 v2.0（标准） | 10 | 30 |
| 星辰大模型 v2.0（精调版） | 20 | 60 |

**月免费额度**：1,000 万 tokens（输入 + 输出）
