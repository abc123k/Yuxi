# 星辰科技 2026 年 Q1 季度经营报告

## 摘要

2026 年第一季度，星辰科技有限公司实现营业收入 8,200 万元，同比增长 35%，净利润 1,230 万元，同比增长 42%。核心业务「智能客服平台」和「知识图谱构建平台」均保持快速增长。

## 业务线进展

### 1. 智能客服平台

- 签约客户：招商银行信用卡中心、比亚迪供应链管理部
- 新增功能：多轮对话优化、工单自动分类、情感分析模块
- 日均处理对话量：120 万次
- 客户满意度：94.3%

**负责人**：刘志强（VP 销售）
**技术支持**：陈思琪（前端组）、周建华（后端组）

### 2. 知识图谱构建平台

- 签约客户：北京协和医院信息科、上海市第一人民医院
- 新增功能：LightRAG 自动图谱构建、图谱可视化编辑器
- 平台日均处理文档量：5,000 页
- 已构建最大图谱规模：23 万实体、85 万关系

**负责人**：李博文（CTO）
**技术支持**：黄伟（算法组）、林小雅（产品组）

### 3. 大模型 API 服务

- 自研「星辰大模型 v2.0」正式对外开放 API
- 参数规模：70B，支持多模态输入
- 日均 API 调用量：50 万次
- 主要客户：新东方教育科技集团、清华大学继续教育学院

**负责人**：黄伟（AI 实验室主任）

## 风险与挑战

1. **GPU 算力成本持续上升**：Q1 GPU 算力支出 800 万元，占总支出 11%，需考虑算力优化或采购策略调整
2. **人才竞争激烈**：算法工程师招聘周期延长至 45 天，需提升薪酬竞争力
3. **海外业务合规**：新加坡办事处涉及数据跨境，需加强合规审查

**风险管理负责人**：赵国强（CFO）、王晓琳（COO）
